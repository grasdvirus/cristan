# **App Name**: Mon Portfolio Personnel

## Core Features:

- Hero Section: Displays a hero image or slider with a brief introduction and navigation buttons to other sections on the homepage.
- Framework Grid: Displays projects or works in a gridded layout.
- Video Embed: Showcase embedded videos.
- Video Interaction: Allow users to like and comment on the embedded videos. Includes database storage of the likes and comments
- Profile Page: Dedicated page to display a detailed profile with bio, skills, and contact information.
- Theme Customization Tool: A tool driven by generative AI that intelligently switch between light and dark mode (neumorphism style) automatically, based on user preferences, system settings, or time of day. 

## Style Guidelines:

- Primary color: Light grey (#E0E5EC) for a soft background, in line with neumorphism.
- Background color: Very light grey (#F0F0F0), nearly white, creating a subtle contrast for the neumorphic effect.
- Accent color: Dark grey (#333333) for text and interactive elements to ensure readability and contrast. It complements the theme with the option for a smart theme switch, as the opposite theme will feature #E0E5EC text on a #333333 background.
- Font pairing: 'Poppins' (sans-serif) for headlines and 'PT Sans' (sans-serif) for body text, for a modern and readable combination.
- Use simple, minimalist icons in dark grey, consistent with the neumorphic style, for likes, comments, and navigation.
- Employ a grid-based layout for the framework section, ensuring content is well-organized and visually appealing.
- Subtle, soft animations for hover effects and transitions, enhancing the neumorphic feel.
